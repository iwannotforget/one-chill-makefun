A single line of horror, entered in make.fun's One Line, One Chill.
The whole entry is one sentence of at most 200 characters; `main.ts`
(Node 22, standard library only) writes it to `/output/entry.txt`:

> My wife has talked in her sleep for years, but last night she spoke in my voice, turned her face to the wall, and whispered, 'He's pretending to be asleep again.'

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
